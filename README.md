# Portfolio Website

A responsive, editable portfolio built with HTML, CSS, and JavaScript. No framework or build step is required.

## Open the site

Open `index.html` directly in your browser, or run:

```powershell
cd "C:\Users\Liondami\Documents\ITWeb"
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

- Edit your personal details in `index.html`.
- Add or update projects in the `projects` array in `script.js`.
- Change the theme colors in `styles.css`.
- Replace the placeholder contact information and social links.

## Features

- Responsive desktop/mobile design
- Light and dark modes
- Project category filters
- Interactive project detail dialogs
- Scroll animations
- Keyboard-accessible project cards
